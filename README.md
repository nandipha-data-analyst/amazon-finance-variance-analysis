Amazon-Style Financial Variance Analysis

Intern Project | Cape Town, South Africa



**Objective**: 

Analyze budget vs. actual financial performance, identify key variances, and provide data-driven insights using Amazon's Dive Deep principle.





📁 **Project Structure**

\- `data/` - Raw budget vs actual data (CSV)

\- `notebooks/` - Python analysis (pandas, variance calculation)

\- `dashboard/` - Excel dashboard with PivotTables, VLOOKUP \& conditional formatting



**🔧 Tools Used**

\- **Excel**: PivotTables, VLOOKUP, Variance formulas, Conditional Formatting, Charts

\- **Python**: pandas, matplotlib for trend analysis

\- **Amazon Leadership Principle**: Dive Deep \& Bias for Action



📊 **Key Insights**

\- Marketing overspent by 12.5% in March - driven by Q1 campaign launch

\- Operations saved 8.2% through vendor renegotiation

\- Total variance: -2.1% under budget (Favorable)

\- Recommendation: Reallocate 5% from Operations savings to Technology upgrade
